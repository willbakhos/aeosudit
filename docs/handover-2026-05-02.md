## What's shipped & working

### Audit engine
- **5 AI engines** queried in parallel via OpenRouter + Apify: Claude (Haiku 4.5), ChatGPT (GPT-5-mini), Perplexity (Sonar), Gemini (2.5 Flash), Google AI Overviews (Apify SERP scraper)
- **4 tiers**: free (Google only, 8 queries), spotlight ($49 — Google + 1 chosen engine, 20 queries), full ($149 — all engines, 40 queries, LLM scoring), action_plan ($349 — full + Sonnet recommendations)
- **Deterministic + LLM scoring**: regex on brand text, URL parse on citations, Haiku second-pass for sentiment/accuracy/hallucinations
- **Action plan generator** ([src/action_plan.py](src/action_plan.py)): Sonnet returns 8–12 prioritised recommendations with example markup
- **Tech AEO/GEO audit** ([src/tech_audit.py](src/tech_audit.py)): 15 checks scored 0–100 — robots.txt for AI bots, sitemap, llms.txt, schema.org markup, OG/Twitter, canonical, H1, server-render, viewport, HTTPS, response time
- **Cost reports**: text + JSON + visual HTML in [src/cost_report.py](src/cost_report.py)
- **Screenshot capture** via screenshotapi.net (1280×800, follows redirects)

### Reports
- **Free report** ([templates/report_free.html.j2](templates/report_free.html.j2)): hero with takeaway, engine selector with locked engines, tech section (3 visible / 12 blurred with unlock pill), pricing CTA
- **Paid report** ([templates/report.html.j2](templates/report.html.j2)): full tech section, action plan, hallucination flags, engine heatmap, citation map, per-query drill-down
- Both use the design system documented in [docs/design-system.md](docs/design-system.md)

### Marketing site
- 11 routes wired in [src/server.py](src/server.py): `/`, `/pricing`, `/what-is-aeo`, `/what-is-geo`, `/aeo-vs-seo`, `/product/audit`, `/product/monitoring`, `/how-it-works`, `/privacy`, `/terms`, `/support`
- Free-preview form on `/` posts to `/preview` → spawns background tech+AI audit → polls `/preview/{run_id}/status` → redirects to `/report/{run_id}` when done (~20–30s for free tier)
- "Run another preview" floating CTA on every report
- All pages share [_layout.html.j2](templates/_layout.html.j2) with nav + dropdown + footer

### SEO/AEO foundations on our own site
- Per-page `<meta name="description">`, canonical, OG, Twitter Card
- Sitewide JSON-LD: Organization + WebSite
- FAQPage schema on `/pricing` and `/aeo-vs-seo`
- Product schema (3 tiers) on `/pricing`
- Article schema on `/aeo-vs-seo`
- Service schema on `/product/audit`
- `/robots.txt` with explicit allow for GPTBot, ClaudeBot, PerplexityBot, Google-Extended, anthropic-ai, cohere-ai
- `/sitemap.xml` auto-generated

### Stripe + delivery (built but not configured)
- [src/server.py](src/server.py): `POST /checkout`, `POST /webhooks/stripe`, `GET /report/{run_id}`, `GET /report/{run_id}/pdf`
- [src/delivery.py](src/delivery.py): Resend email with hosted link + PDF attachment
- [src/pdf.py](src/pdf.py): WeasyPrint HTML→PDF with screenshot inlined as base64
- Support form sends ticket via Resend
- Monitoring waitlist signup endpoint

## Known issues — fix order

### Critical (do first)
1. **Apify `aiOverview.content` returns blank** for many queries. Citations come through fine, but `response_text` is empty → visibility scoring shows 0% when the brand should actually appear. The free report ends up underselling the brand's real situation. **Fix:** in [src/engines/apify.py](src/engines/apify.py) `_parse()`, look at the actual structure (`aiOverview.content` may be a list of blocks with `text` fields rather than a flat string). Inspect a fresh `raw_responses.json` to see real shape.
2. **Perplexity model ID `perplexity/sonar` returns 404** on every call. Need to look up the current Perplexity model on openrouter.ai/models — likely `perplexity/sonar-small-online` or `perplexity/sonar-reasoning`. Until fixed, every audit shows "0/40 — error" for Perplexity.

### Medium
3. **WeasyPrint needs system libs** for PDF generation: `brew install pango glib`. Code falls back gracefully (skips PDF, still emails the hosted link).
4. **No real OG image at `/static/og-default.png`** — needs a 1200×630 PNG. Currently 404s when shared on Slack/Twitter/LinkedIn.
5. **`PREVIEW_JOBS` dict is in-memory only** in [src/server.py](src/server.py) — won't survive a uvicorn restart and doesn't scale to multiple workers. Swap for Redis or SQLite when going to production.
6. **No rate limiting on `/preview`** — someone can spam the form and burn through Apify credits ($0.03/submission). Add Cloudflare Turnstile or per-IP throttle before launching publicly.

### Low (nice to fix)
7. Screenshotapi sometimes returns the same cached image even with `fresh=true`. Worth a follow-up to confirm whether their plan ignores that flag.
8. The cost-report tool doesn't account for the new tech-audit cost (it's $0 — pure HTTP fetches + parsing — but worth showing).

## What's not done — build queue

### Before you can sell anything
1. **Deploy to production.** Railway is fastest — connect the GitHub repo, add env vars, get a public URL in 5 minutes. WeasyPrint's system deps are pre-installed on their Linux base. Alternative: Fly.io or Render. Avoid Vercel/Netlify — audits run too long for serverless.
2. **Buy real domain + point it.** Currently `_base_url` defaults to `https://aeoaudit.com`. Either buy that or change `PUBLIC_BASE_URL` env var to whatever you settle on.
3. **Stripe price IDs** — create three prices in the Stripe dashboard ($49 / $149 / $349) and put the IDs in env vars `STRIPE_PRICE_SPOTLIGHT`, `STRIPE_PRICE_FULL`, `STRIPE_PRICE_ACTION_PLAN`.
4. **Resend domain verification** — add the domain to Resend, verify SPF/DKIM, set `REPORT_FROM_EMAIL`.
5. **Test Stripe checkout end-to-end** with a test card. The webhook flow has never been exercised against a live Stripe.

### Marketing
6. **Generate a real OG image.** 1200×630 PNG. Brand mark + tagline + screenshot of a sample report. 15 min in Figma/Canva.
7. **Run our own audit** once deployed. Publish the result as marketing ("We audited ourselves and got 67/100 — here's how we'll fix it"). Strong content for HN, Indie Hackers, Twitter.
8. **Submit to Product Hunt + HN + Indie Hackers** for inbound citation flywheel.

### Product
9. **Monitoring tier** ($99/mo). The page exists at `/product/monitoring` but it's marketing-only — the recurring audit runner doesn't exist yet. Build it as a simple cron job that re-runs the full audit monthly and emails the diff.
10. **Agency white-label.** $399/mo for 10 client domains. Workspace concept needs schema + UI.

| Var | Used for |
|---|---|

## What I'd do differently if I had today again

- Build the tech audit BEFORE the marketing site. Foundation features first.
- Test the Apify response shape with multiple real queries before relying on it. Wasted a couple of cycles on the empty-content bug.
- Use `select_autoescape(default=True)` from day one. The `.html.j2` extension trap cost two debug rounds.
